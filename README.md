# Campo Reader

用 PyQt6 编写的 FAU Campo 课表与成绩查看器。日常查看读取本地缓存，登录同步时访问 Campo 官方网站。支持多个本地账号，每个账号有独立的登录会话和数据。

## 安装与启动

Windows 安装过 Anaconda 或 Miniconda 后，直接双击 **`Start-Campo.cmd`**。启动器自动查找 conda，首次创建专用环境，检查并补齐依赖，然后打开程序；后续启动使用已有环境。首次安装需要网络连接。

`Start-Demo.cmd` 可一键启动演示模式。启动失败会保留终端提示，程序错误日志位于 `data/launch-errors.log`。

也可以在项目目录打开 Anaconda Prompt，手动安装：

```bat
conda env create -f environment.yml
conda activate campo-reader
python main.py
```

环境准备好后，也可以在 Windows 上双击 `Start-Campo.cmd`。

也可以在 Anaconda Prompt 中运行：

```bat
conda activate campo-reader
python main.py
```

## 第一次使用

1. 点击“添加账号”，填写名称，例如 FAU 用户名。这个名称是本地标签。
2. 在原生“登录信息”窗口中填写 FAU 用户名和密码，可勾选“记住登录信息”。已有账号可点击主窗口的“登录信息”修改。
3. 程序后台登录 Campo，自动读取课表和成绩，仅显示同步进度，不弹出网站。记住信息后，启动或切换账号时会检查缓存是否超过 10 分钟，过期时自动同步；点击“同步”始终立即更新。
4. 同步完成后，在主窗口查看课表和成绩。添加其他账号时重复以上操作。

账号首次同步时，程序使用 Campo 日历的个人标识绑定账号。后续发现标识不一致时会拒绝覆盖该账号缓存。主窗口会显示 Campo 返回的姓名，可核对当前身份。

账号标签填写错误不影响数据来源；实际数据由“登录信息”中填写的 FAU 账号决定。如首次绑定了错误身份，移除这个本地账号后重新添加。

## 功能

- 课表：按周查看，按课程或教室搜索；课程冲突会并排显示；点击课程看详情。列表页支持双击详情。
- 窗口布局：顶部信息固定为单行，过滤旧缓存的整个学期列表；时间轴按窗口高度调整。
- 日历同步：处理重复课程、取消日期、改期、全天事件及德国夏令时。每次同步缓存过去 180 天至未来 365 天的日历条目；超出范围的周会提示重新同步。
- 成绩：分别查看具体考试、模块或全部层级，按专业筛选，搜索课程、编号和状态。
- 成绩汇总：显示 Campo 的原始汇总记录，不把模块、考试和汇总学分相加，也不自行计算均分。
- 多账号：独立 Qt 浏览器会话、独立缓存；切换立即加载对应数据。
- 容错：两项数据均成功读取后才替换缓存；请求失败、登录超时、成绩未完全展开时保留旧快照。
- 同步提速：复用运行期间的账号会话，课表下载和成绩读取并行执行；先完成的一项先预览，失败或取消后恢复完整旧缓存。

## 登录与本地数据

程序不读取 Chrome cookies，日历订阅链接只存在内存中。每个账号的登录会话独立，关闭程序后清除。勾选“记住登录信息”后，成功同步时会将用户名和密码通过 Windows DPAPI 加密保存在本机；下次可以自动登录。取消勾选会清除已保存的登录信息，当前运行期间仍可同步。Qt 的无痕 profile 行为参见 [Qt 官方文档](https://doc.qt.io/qt-6/qwebengineprofile.html#isOffTheRecord)。

真实数据默认位于 `data/campo.sqlite3`。在 Windows 上，缓存内容通过当前 Windows 用户的 DPAPI 加密；账号标签仍以明文保存。应使用同一个 Windows 用户打开缓存，不要把数据库当作跨电脑备份。非 Windows 系统运行时缓存为普通 JSON blob。

订阅标识发生变化（例如在 Campo 重新生成安全凭证），可能需要移除本地账号后重新绑定。移除仅影响本机数据。

## 速度与限制

主窗口使用缓存，打开和切换账号不依赖 Campo 响应。登录和同步仍依赖 Campo 服务器速度；这是第一版实际提供的加速方式。

0.3.0 缩短了阶段轮询，用 AJAX 完成状态和表格安静时间检查成绩，不再固定按秒等待。2026-10-14，在本机用同一已配置账号测得旧流程 16.00 秒，新流程两次分别为 11.19、11.39 秒，约减少 30%。这是少量实测，实际时间会受 Campo 服务器和网络影响；状态栏会显示本次同步用时。

10 分钟内的完整缓存用于自动刷新判断，手动“同步”始终发起完整更新。课表或成绩会在读取完成后先显示，只有两项都通过校验才保存完整快照。

自动登录每次只提交一次账号密码。密码错误、额外验证码、二次验证或登录页面变化时会停止并提示；不自动反复重试。请在“登录信息”修改后重新同步。

当前读取适配了 Campo 的 JSF 页面及英文、德文成绩表结构。若在 Campo 自定义了成绩表列，请恢复含名称、编号、成绩、状态、ECTS 的默认列后同步。网站结构变化可能需要更新 `scripts.py`。

本版本查询课表和成绩。程序读取当前成绩页选中的专业记录，并提供已经读取到的专业筛选；暂不自动切换成绩页的历史学籍或专业勾选项。

FAU 的官方课表导出说明见 [课表与日历导出](https://www.fau.de/studium/studienorganisation/studienstart/stundenplan-und-vorlesungsverzeichnis/stundenplaene-fuer-studierende-in-campo/)。

## 在其他电脑安装

在此目录打开 Anaconda Prompt：

```bat
conda env create -f environment.yml
conda activate campo-reader
python main.py
```

如果已有合适的环境：

```bat
python -m pip install -r requirements.txt
python main.py
```

## 演示和验证

```bat
python main.py --demo
python -m pip install pytest
python -m pytest tests -q
```

演示数据单独保存在 `data/demo.sqlite3`，包含虚构的两组账号。演示模式仅用于界面体验，请通过正常启动使用真实账号。

已在 Windows / Python 3.12 上验证原生 Qt 界面、Campo 登录识别及成绩列布局，并完成真实账号的自动登录和课表、成绩同步。

27 项自动测试通过，覆盖账号隔离、拒绝错账号覆盖、Windows 加密、日历重复与例外、夏令时、德英成绩表、界面切换、完整同步后才提交和失败保留缓存、旧学期缓存的布局回归、加密登录信息、官方表单后台提交、并行完成顺序、异步表格更新、停滞超时、短期缓存复用、临时预览恢复，以及启动器的环境识别、首次安装、依赖修复和失败提示。多账号隔离通过自动测试；尚未用两个真实 FAU 账号同时验证。
